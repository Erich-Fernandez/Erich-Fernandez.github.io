### 1. Motivation


Suppose we have a trading strategy that can be continuously changed at any time and is specified by parameters. Suppose we also have a function 
$$
f(\text{time} = t, \text{strategy} = (\text{parameter}_i)_{i=1}^n)
$$ 
that tells us our expected profit if we utilize strategy $$(\text{parameter}_i)_ {i=1}^n$$ at time $t$. 

Of course, we will be interested in the function $F(t)$ such that 

$$
F(t) = \underset{x\in\{\text{valid strategies}\}}{\text{max}} f(t, x)
$$

We might be interested in doing things with this function $F(t)$, like say integrating it in order to get our total expected profit across a time period. However, we run into a huge problem. How do we know that this function $F(t)$ is even measurable? This is the motivation for the succeeding theorem, which I will state and (roughly) prove. 


<div class="theorem-box" markdown="1">

 **Measurable Selection Theorem** 
Let $E$ be a compact metric space, $(\Omega, \mathscr{F})$ and $\psi:E\times\Omega\to \mathbb{R}$ be a mapping satisfying:
 
 (i) $$\forall x\in E, \omega \mapsto \psi(x, \omega)$ is measurable. $$
(ii) $$\forall\omega\in\Omega, x\mapsto \psi(x, \omega)$ is continuous. $$
    Then, there exists an $E$-valued measurable function $X:\Omega\to E$ such that $\psi(X(\omega), \omega) = \sup_{x\in E} \psi(x,\omega)$.
</div>


### 2. Preliminaries
The proof uses the novel idea of the Effros Borel space.

{: .box-warning}
**Definition:** Given a topological space $X$, we first define $F(X)$ as the set of closed sets in $X$. The Effros Borel space is the $\sigma$-algebra on $F(X)$ generated by the collections $$\{ F\in F(X)~|~F\cap U\neq \emptyset \}$$.

Note that this is a subbasis collection and thus it suffices to deal with these sets only in order to prove measurability. Furthermore, in the case that $X$ is a metric space, we can further restrict this collection to only bounded open balls.

I will now state without proof (the proof is via a construction called the Souslin scheme that transforms a nice class of topological spaces into a tree/node-like structure) the meat of the proof:

<div class="theorem-box" markdown="1">

**Kuratowski-Ryll-Nardzewski**
Let $X$ be a separable, completely metrizable topological space. Then, there exists a measurable function $S:F(X)\to X$.
</div>

### 3. The Proof
Going back to the proof of the measurable selector theorem, we begin by considering the sets

$$ F(\omega) := \{ x\in E~|~\psi(x,\omega) = \sup_{x\in E} \psi(x,\omega) \}. $$

Note that this set is closed because it is the inverse image of the continuous map $x\mapsto \psi(x,\omega)$ of the singleton (closed) set containing the point $\sup_{x\in E} \psi(x,\omega)$.

The remainder of our proof consists of showing that the map $d:\Omega\to F(E)$ by $d(\omega) = F(\omega)$ is measurable. The proof then follows by Kuratowski-Ryll-Nardzewski. 

Let $U$ be a bounded open set in $E$. We need to show that the following set is measurable:

$$ A:= d^{-1} ( \{ F\in F(X)~|~F\cap U\neq \emptyset \} ) = \{\omega \in \Omega~|~K(\omega) \cap U \neq \emptyset\}. $$

We first take note that it is unwieldy to deal with open sets in this context since $K(\omega)$ is a set of supremums. The first step is to make the problem easier by approximating $U$ with compact sets. Let $U_n = \text{cl}(U) \cap B(\partial U, \frac1n)^c$. Consider now: 

$$ A_n :=  \{\omega \in \Omega~|~K(\omega) \cap U_n \neq \emptyset\}. $$

Take note now that $A = \cup A_n$ and so it suffices to prove the measurability of each $A_n$ in order to get measurability of $A$.

But now, note that $K(\omega) \cap U_n \neq \emptyset$ means "the supremum value is attained by some element of the compact set $U_n$". 

But now, this is clearly measurable by introducing the following trick. Remembering that every compact metric space is separable and so consider $(e_n)$ a countable dense subset. 

Note the following now:

$$
\begin{align*}
K(\omega) \cap U_n \neq \emptyset &\iff \sup_{x\in U_n} \psi(x,\omega) = \sup_{x\in E} \psi(x,\omega) \\
&\iff \sup_{e_j\in U_n} \psi(e_j,\omega) - \sup_{j\in \mathbb{N}} \psi(e_j, \omega) = 0
\end{align*}
$$

Take note that the countable supremum of measurable functions is measurable, and so the function in the LHS of the last equation is actually a measurable function and thus the following is a measurable set:

$$
\begin{align*}

A_n &= \{ \omega \in \Omega~|~K(\omega) \cap U_n \neq \emptyset \} \\
    &= [\sup_{e_j\in U_n} \psi(e_j,\omega) - \sup_{j\in \mathbb{N}} \psi(e_j, \omega)]^{-1} (\{ 0 \}).

\end{align*}
$$
